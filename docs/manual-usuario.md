# Manual de usuario — SigaWatch

Dirigido a agricultores y técnicos de campo de fincas bananeras de Urabá.

1. **Ingresar.** Escribe tu correo y contraseña y toca *Iniciar sesión*. También puedes entrar con Google o SMS.
2. **Revisar el panel.** Arriba ves cuántas zonas tienes, cuántas están en alto riesgo y los reportes del día.
   Si hay una alerta roja, tócala para ver el detalle.
3. **Reportar un foco.** Toca el botón verde central con la cámara:
   1. Toma la foto de la hoja afectada.
   2. Espera a que el GPS marque tu ubicación (es automático) y confirma la zona.
   3. Elige la severidad: Leve, Moderada, Severa o Crítica.
   4. Toca *Enviar reporte*. Recibirás un código y las fincas cercanas serán avisadas.
4. **Ver el riesgo.** En *Riesgo* eliges la zona y el modelo de cálculo. Revisa las variables del clima y las
   recomendaciones.
5. **Ver el mapa.** En *Mapa* filtras los focos por nivel de riesgo y tocas cada punto para ver el detalle.
6. **Atender alertas.** En *Alertas* filtras por activas o leídas; toca una alerta para marcarla como leída.
7. **Notificaciones ICA (v1.1.0).** Si reportas un foco Severo o Crítico, la app lo notifica al ICA
   automáticamente. En el panel toca *Notificaciones ICA* para ver el radicado y reenviar las pendientes.

Colores: **rojo** = riesgo alto, **naranja** = medio, **verde** = bajo.
